# mujoco
- Tải mujoco: Vào trang chính thức download, sau khi giải nén vào bin để khởi động. https://www.youtube.com/watch?v=aLBpv3i9TFc
- Drag file main vào màn hình khi mujoco khởi động, điều khiển các trục tay robot vào phần control ở phía bên phải màn hình
- Có file test chuyển động và test camera cùng cấp với file main. File test nên chạy bằng terminal sẽ không bị lỗi: Ví dụ (python test_camera.py)
- Chưa tích hợp thêm mujoco_menagerie nhưng có thể sử dụng code đó để điều khiển các hành động của cánh tay robot do đã được code sẵn hết.
- Xem hướng dẫn dùng cánh tay tại link youtube: https://www.youtube.com/watch?v=G-R2CrsFC-I&t=367s
